# Ọlá Trails

> **Luxury pan-African safari booking platform — Follow the Path of Prestige**

A full-stack safari booking platform connecting high-end travellers with curated safari experiences across Africa. Features a polished client-facing interface, a complete booking flow with email confirmations, and an admin panel for operators — shipped with realistic pre-seeded demo data.

🔗 **[View Live Site](https://ola-trails.up.railway.app/)**

![Ọlá Trails](ola%20home.jpg)

## Features

- **Experience browser** — filter safaris by region (East Africa, Southern Africa, North Africa, West Africa, Central Africa), category, price, and duration
- **Full booking flow** — guest details, date selection, group size, special requests, with reference number generation
- **Email confirmations** — automated booking confirmations via Nodemailer
- **Admin panel** — manage safari listings, reservations, pricing, and availability
- **Pre-seeded demo data** — database populated with realistic safari experiences on first run
- **Zero-config setup** — SQLite auto-created and seeded on first run, no database configuration needed
